# Examples

## Pin-Cell Demo

The repository includes a generated pin-cell mesh in `demo/pincell.json`.

```julia
using Gridap
using RayTracing

model = DiscreteModelFromFile(joinpath("demo", "pincell.json"))
tg = TrackGenerator(model, 8, 0.08; bcs=reflective_boundaries())

trace!(tg)
segmentize!(tg)

tg.n_total_tracks
sum(length(track.segments) for track in tg.tracks_by_uid)
```

For larger track sets, run Julia with multiple threads and opt in to threaded segmentation:

```julia
segmentize!(tg; parallel=true)
```

## Plotting Tracks

RayTracing plotting recipes are enabled when Plots.jl is loaded:

```julia
using Plots

plot(tg.mesh)
plot(tg)
plot(tg.tracks_by_uid)
```

The README assets are generated by `demo/pincell.jl`, which writes:

- `demo/pincell-msh.png`
- `demo/pincell-tracks.png`
- `demo/pincell-segments.png`
- `demo/cyclic_track_no_mesh.gif`
- `demo/cyclic_track_with_mesh.gif`

## Exact Volume Correction

By default, `tg.volumes` contains volumes reconstructed from ray segments. If exact
geometric cell areas are needed, enable `volume_correction`:

```julia
tg = TrackGenerator(
    model,
    8,
    0.08;
    bcs=reflective_boundaries(),
    volume_correction=true,
)

trace!(tg)
segmentize!(tg)
tg.volumes
```

## Regenerating the Mesh

The gmsh source for the demo mesh is in `demo/pincell-gmsh.jl`. It writes both the `.msh`
and Gridap `.json` mesh files next to the script. Run it in an environment that has
GridapGmsh installed:

```bash
julia demo/pincell-gmsh.jl -nopopup
```
